# JASS Collage Studio — Merged v1.4.0

This release uses the supplied JASS Collage Studio source as its base and
merges the later UI fixes/features.

## Merged improvements

- Scrollable right settings panel
- Minimum readable button height
- Minimum readable combo-box height
- UI Text WHITE / BLACK toggle
- Explicit Windows palette colors for buttons, labels and combo boxes
- Existing photo editing features preserved
- Existing templates preserved
- Existing text, shape, frame, shadow, lock and alignment features preserved
- Existing PNG/JPEG export preserved

## Run

```powershell
python JASS_Collage_Studio.py
```

Requires:

```powershell
python -m pip install PySide6
```
